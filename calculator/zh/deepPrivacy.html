隐私政策

适用应用： Calculator√ · 生效日期： 2026-10-14

Calculator√ 在设备上完成计算。我们不运营用于保存你计算历史的服务器，不要求账号，也不接入广告或第三方分析 SDK。汇率请求不附带你的计算内容。

网络服务商会接收到处理连接所需的信息。如果你联系支持或分享结果，由你决定发送哪些内容。下文分别说明这些情况。

1. 信息收集范围

应用为提供功能及恢复现场，在本地应用存储中保存：

我们不会自动上传你的算式、金额、历史、备注、标签或记忆值。应用没有账号、广告标识符、广告 SDK、第三方分析 SDK 或第三方崩溃上报 SDK。应用不请求定位、通讯录、照片、相机、麦克风、健康数据或音乐访问权限。读取系统地区以选择初始币种，不等于获取你的位置。

  • 当前算式、结果、计算模式、角度单位、币对和输入方向。
  • 计算历史、当时的货币报价快照、收藏、备注、标签、全局记忆卡片和科学记忆。
  • 外观、语言、数字字符、分隔符、小数精度、声音、触觉和常用币种偏好。
  • 缓存汇率、供应商标识，以及请求时间、报价时间和最近成功刷新时间。
  • 成功计算的本地计数和上次系统评分请求时间，仅用于控制评分弹窗频率。

2. 我们如何获取信息

只有你明确选择“粘贴”时，应用才读取剪贴板文字；跨应用粘贴的权限提示由 iOS 管理。文字在本地处理，不发给开发者或汇率服务。

“复制”将所选文字写入系统剪贴板。分享和 CSV 导出使用系统分享界面；你选择的接收方、应用或存储位置可能获得相应内容，并按其自己的规则处理。我们不会自动替你选定接收人或发送记录。分享流程完成后会移除临时导出文件，iOS 也会管理临时存储。

3. 我们如何使用信息

本地信息仅用于计算、恢复输入现场、管理历史与记忆、应用偏好及控制系统评分请求频率。汇率请求仅用于取得参考报价。我们不将这些信息用于广告、用户画像或出售。

4. 第三方共享、转让与公开披露

应用通过 HTTPS 连接 Frankfurter 获取法币报价，使用 ExchangeRate-API 作为备用，并通过 Yadio 获取可选 BTC 报价。请求的是参考报价表，不附带你的金额、算式、备注、标签、历史、剪贴板文字或应用自行生成的用户标识。

建立网络连接会使接收服务及其基础设施获得处理连接所需的信息，例如 IP 地址和技术请求头。是否记录、保存这些信息，由各服务商的实际政策决定。Frankfurter 在文档中说明其隐私规则；ExchangeRate-API 的条款页面包含隐私政策；Yadio 提供其服务条款。

报价及刷新元数据保存在本地，更新失败保留已有缓存。第三方基础设施可能在你所在国家或地区以外处理请求。我们不运营这些汇率服务，也不能控制它们的信息保存规则。

应用下载、更新、系统评分，以及你通过 iOS 设置选择分享的诊断，由 Apple 按其设置和政策处理。应用可能在使用后请求系统原生评分界面；用于限频的计数和时间保存在本地。应用无法判断你评了几星、是否提交评价或弹窗是否显示。公开的 App Store 评价可能被开发者及其他人查看。

本静态网站由 GitHub 的 GitHub Pages 托管。网页不另加分析脚本、广告追踪器、Cookie 或反馈提交后台。GitHub 可能按其隐私声明处理连接技术信息；点击外部链接或发送邮件后，相关操作由目的服务处理。

5. 信息如何存储与保护

本地记录会保留到你主动删除、替换相关数据，或在 iOS 中选择“删除 App”。“卸载 App”通常保留数据。本地存储使用应用沙盒和 iOS 数据保护，汇率请求使用 HTTPS；任何系统都不能承诺绝对安全。

根据设备备份设置，应用数据可能包含在设备或 iCloud 备份中。备份和已导出文件独立于应用当前存储，需要通过 Apple 或你选择的目的地管理。删除本地历史不会撤回已分享文件。

你可以修改偏好、删除单条或当前匹配的历史记录、管理标签和记忆卡片，以及导出历史。获取新报价需要网络；离线计算和已缓存报价不需要新请求。
